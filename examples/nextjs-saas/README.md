# Example: Next.js SaaS

Installed instruction set for a Next.js App Router app that uses React, Tailwind CSS, shadcn/ui, and Prisma.

```bash
npx agentkit-rules --stacks core,nextjs,react,tailwind,shadcn,prisma --target .
```

`package.json` records the dependencies the installer would detect. It is not a runnable application. Regenerate the instruction files from the repository root with `npm run examples`.
