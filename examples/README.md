# Examples

These directories are the installer's output, committed so you can read a full result without running it.

| Directory | Stacks |
| --- | --- |
| [nextjs-saas](./nextjs-saas) | core, nextjs, react, tailwind, shadcn, prisma |
| [nestjs-api](./nestjs-api) | core, node, nestjs, drizzle |

Each `package.json` exists so the chosen stacks match what detection would pick. Neither directory is an application.

Refresh both from the repository root:

```bash
npm run examples
```
